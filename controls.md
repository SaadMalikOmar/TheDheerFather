# Controls — The Dheer Father (current build)

## Everyone
| Key | Action |
|-----|--------|
| WASD / mouse | Move / look |
| Shift | Sprint (full bar = 3× locked; SUPER RUN charges auto-spend) |
| Ctrl | Slow walk |
| Space | Jump — **hold at a tree trunk to CLIMB**; add **Ctrl to hang on** |
| **E** | **Interact** — sit, hide, routers, repairs, revives, car |
| F | Hold breath (runners) |
| LMB | Swing weapon |
| B | Character select · 1–6 runners · 7–9 killers |
| C | Vehicle (legacy Lucki enter/exit) |
| H | Host: start match / launch from party lobby |
| F1 / F2 | Host LAN / Join LAN |
| 8 / 9 / 0 | Difficulty: Casual / Normal / Hardcore |
